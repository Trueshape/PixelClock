# PixelClock — regole per l'AI

- Leggi prima `PROJECT.md` (scopo e stato), `overview.md` (file) e `decisions.md` (scelte).
- Ogni file inizia con un commento di una riga su cosa fa.
- Aggiorna overview.md quando aggiungi file, decisions.md quando fai una scelta importante.
- Verifica visiva: `npm run snapshot` salva snapshot.png e chiude.
